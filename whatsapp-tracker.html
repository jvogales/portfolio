[ 02 ] O PROJETO

Da mensagem
ao histórico.

O WhatsApp Tracker conecta uma interface web a uma API que roda no próprio computador. A conexão com o WhatsApp Web é feita por QR Code, e as mensagens recebidas e enviadas passam a compor um histórico local.

O objetivo é facilitar o backup e a consulta das próprias conversas, reunindo texto, mídia e informações de cada mensagem em uma interface organizada.

A aplicação também é um estudo de separação de responsabilidades: interface, regras de negócio e acesso ao banco de dados trabalham em camadas distintas.

[ 04 ] POR DENTRO

Responsabilidades
bem definidas.

O frontend usa JavaScript e CSS sem framework. No backend, Node.js e Express expõem a API, enquanto o Prisma organiza o acesso ao SQLite. A conexão com o WhatsApp é feita pela biblioteca whatsapp-web.js.

  1. Interface webConsulta e apresentação das conversas.
  2. Controllers e servicesRequisições HTTP e regras de processamento.
  3. Repository e bancoPersistência e leitura dos dados com Prisma e SQLite.

Escopo e limitações

O projeto foi desenvolvido para backup pessoal das próprias conversas. Não é uma integração oficial do WhatsApp e pode precisar de ajustes quando o serviço muda. O registro de mensagens excluídas depende de elas terem sido capturadas anteriormente e da identificação do evento pela biblioteca.
